Публичный дашборд KPI ТПЗ. Содержит классический трекер и современные представления: Навигатор, Диагностика и Пульс.

## Источник данных

- Google Таблица: **KPI ТПЗ**
- Лист: **ТПЗ** (gid `1052433588`)
- Таблица используется только для чтения.
- Дашборд пытается обновлять данные при открытии страницы и затем каждые 10 минут.
- При ошибке загрузки остаются последние встроенные данные; статус синхронизации показывает ошибку.

## Важно о доступе

Репозиторий и сайт публичные. Все показатели, встроенные в HTML, и данные, доступные через публичную ссылку Google Таблицы, могут быть прочитаны посетителями. Не используйте здесь конфиденциальные данные или секреты.

Изменения через локальный ввод в интерфейсе сохраняются только в браузере и не записываются в Google Таблицу.
